# OptiManager Pro - Guide d'Interface (UI Guide)

Version : 1.0

---

# 1. Philosophie

L'interface doit être :

* Rapide
* Moderne
* Professionnelle
* Épurée
* Facile à apprendre

Un opticien doit pouvoir utiliser le logiciel après quelques minutes.

---

# 2. Couleurs

## Couleur principale

Bleu

Utilisée pour :

* boutons principaux
* titres
* menus

---

## Couleur secondaire

Blanc

Fond des fenêtres.

---

## Couleur d'information

Gris clair

Pour les zones secondaires.

---

## Succès

Vert

Création réussie.

---

## Avertissement

Orange

Attention.

---

## Erreur

Rouge

Messages d'erreur.

---

# 12. Règles

Aucune fenêtre ne doit dépasser 300 lignes de code.

La logique métier n'est jamais écrite dans l'interface.

Toutes les fenêtres utilisent les services.

Les services utilisent les repositories.

Les repositories utilisent SQLAlchemy.
