# 1. Vision

OptiManager Pro est une plateforme ERP spécialisée
dans la gestion complète d'un centre d'optique,
d'optométrie et d'un laboratoire d'optique.

Le logiciel couvre l'ensemble du parcours patient,
depuis la prise de rendez-vous jusqu'au suivi
après livraison.

Le système doit être :

• rapide

• fiable

• sécurisé

• modulaire

• évolutif

• multiplateforme

• orienté métier

---

# 2. Objectifs

Le logiciel doit permettre de :

✔ gérer les patients

✔ gérer les examens

✔ gérer les ventes

✔ gérer le laboratoire

✔ gérer l'atelier

✔ gérer le stock

✔ gérer les fournisseurs

✔ gérer les statistiques

✔ gérer plusieurs magasins

✔ fonctionner hors connexion

✔ synchroniser les données

# 6. Exigences générales

Toutes les données doivent être historisées.

Toutes les opérations importantes sont auditables.

Toutes les actions sont sécurisées.

Toutes les interfaces doivent être homogènes.

Toutes les recherches doivent être instantanées.

Toutes les données doivent pouvoir être exportées.

Toutes les impressions doivent être personnalisables.

Toutes les listes doivent être filtrables.

Toutes les tables doivent être triables.

Toutes les fenêtres doivent être responsives.
